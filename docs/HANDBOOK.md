# wpgctl 实施操作手册（30 分钟版）

## 产品定位

水厂交付的标准作业系统：传包 → 配站 → 部署 → 升级 → 验收，可审计、可回滚。

## SLA

| 场景 | 目标 |
|------|------|
| 新站首次部署（含传包，base 已到位） | ≤ 3 小时 |
| 日常升级 1~3 服务 | ≤ 30 分钟 |
| 配置修改 | 只改 site（表单或 YAML）一处 |

## 两条路径

### A. Windows + Docker Desktop（联调 / 演示）

1. 启动 Docker Desktop，托盘图标变绿  
2. `wpgctl ui --site site.yaml` → 浏览器打开 http://127.0.0.1:9527  
3. 首页选「Windows 联调」  
4. 表单改 IP/密码/模块 → 保存  
5. 拉包或选本地 release 目录 → 部署向导  
6. 注意：不支持 Linux `network_mode:host`

### B. Linux 现场主控（生产）

1. 拷贝 `wpgctl` 二进制 + `site.yaml`  
2. 拉包或 U 盘导入 base（首次）+ release  
3. 同上向导：体检 → 初始化 → 部署  
4. 完成后打开「验收报告」打印/发群

## 日常升级

1. 导入 patch 包  
2. 顶栏填操作者姓名  
3. 「升级」页选 patch → 确认 → 执行  
4. 失败自动回滚镜像；SQL 需人工评估

## 出问题

「下载诊断包」发给公司；或导出交付摘要 JSON。
